# Traefik API 网关集成计划

## 项目现状分析

### 现有结构
- **Casdoor 项目**：Go 后端 + React 前端的 IAM 系统
- **后端服务**：运行在 8000 端口
- **前端服务**：与后端部署在同一端口
- **现有配置**：已存在 `traefik_casdoor_config.yaml` 文件，包含基本的 Traefik 配置

### 现有 Traefik 配置分析
- 已配置 HTTPS 重定向和 TLS 证书
- 已定义 API 和前端路由规则
- 已配置多种中间件（认证、CORS、限流、安全头、压缩等）
- 已配置健康检查和负载均衡

## 集成计划

### 1. 环境准备

#### 1.1 安装 Traefik
- 下载并安装 Traefik v3.0+
- 确保 Traefik 可执行文件在系统路径中

#### 1.2 配置环境变量
- 创建 `.env` 文件，定义以下变量：
  - `CASDOOR_HOST`：Casdoor 的域名
  - `YOUR_CLIENT_ID`：OIDC 客户端 ID
  - `YOUR_CLIENT_SECRET`：OIDC 客户端密钥
  - `YOUR_SESSION_SECRET`：会话密钥

### 2. 配置文件优化

#### 2.1 更新 Traefik 主配置文件
- 修改 `traefik_casdoor_config.yaml`：
  - 完善环境变量引用
  - 优化中间件配置
  - 调整路由规则
  - 配置监控和日志

#### 2.2 创建动态配置目录
- 创建 `/etc/traefik/dynamic` 目录
- 配置动态路由和服务

### 3. 后端配置调整

#### 3.1 修改 Casdoor 配置
- 更新 `conf/app.conf`：
  - 设置 `origin` 和 `originFrontend` 为 Traefik 前端 URL
  - 确保 CORS 配置与 Traefik 一致

#### 3.2 健康检查端点
- 确保后端提供 `/api/health` 健康检查端点
- 配置健康检查逻辑

### 4. 前端配置调整

#### 4.1 修改前端 API 调用
- 更新 `web/src/Conf.js`：
  - 将 API 基础 URL 改为 Traefik API 网关 URL
  - 确保前端能正确通过网关访问后端

#### 4.2 认证回调配置
- 确保前端认证回调 URL 与 Traefik 配置一致
- 测试认证流程

### 5. 部署与测试

#### 5.1 启动服务
- 启动 Casdoor 后端服务
- 启动 Traefik 服务
- 验证服务启动状态

#### 5.2 功能测试
- 测试前端访问
- 测试 API 访问
- 测试认证流程
- 测试健康检查
- 测试中间件功能（CORS、限流等）

#### 5.3 性能测试

### 6. 监控与维护

## 技术要点

### 1. 路由规则设计
- **前端路由**：`https://{CASDOOR_HOST}` → 前端服务
- **API 路由**：`https://api.{CASDOOR_HOST}/api` → 后端 API
- **回调路由**：`https://api.{CASDOOR_HOST}/callback` → 认证回调
- **健康检查**：`https://api.{CASDOOR_HOST}/api/health` → 健康检查

### 2. 中间件配置
- **认证中间件**：OIDC 认证
- **CORS 中间件**：跨域资源共享
- **限流中间件**：防止 API 滥用
- **安全头中间件**：增强安全性
- **压缩中间件**：提高传输效率
- **断路器中间件**：提高系统稳定性
- **重试中间件**：提高请求成功率

### 3. 安全性考虑
- 使用 HTTPS 加密传输
- 配置 TLS 1.3
- 设置安全响应头
- 配置 OIDC 认证
- 限制 API 访问频率

### 4. 高可用性
- 配置负载均衡
- 健康检查和自动故障转移
- 断路器模式
